# v0.5 -- Page Abstraction

---

## 1. Problem Statement

## Visual Model

To build a high-performance database engine, we must transition from writing files sequentially to managing storage in fixed-size blocks called **Pages**. To align memory blocks with physical SSD sectors and avoid write amplification, standard database page sizes are set to 4096 bytes (4KB). We need to design a packed `PageHeader` struct storing metadata, a `Page` struct holding the header and raw data bytes, and compile-time size enforcements.

---

## 2. Step-by-Step Instructions

### Step 1: Create the Page Header Structure
* Open or create the header file `src/storage/page.h` within `namespace DB`.
* Define a global constant `PAGE_SIZE = 4096`.
* Define an `enum class PageType : uint8_t` to declare the different page roles:
  * Types: `METADATA = 0`, `SLOTTED_DATA = 1`, `BTREE_INTERNAL = 2`, `BTREE_LEAF = 3`, `HNSW_NODE = 4`, `FREE_PAGE = 5`.
* Define `struct PageHeader`:
  * Wrap the struct in compiler packing directives to disable padding.
  * Declare the following variables:
    * `lsn` (LSN/int64_t): Log Sequence Number for write-ahead recovery.
    * `pageId` (PageID/int64_t): Logical index of this page.
    * `checksum` (uint32_t): CRC32 validation signature.
    * `pinCount` (uint16_t): Active reader/writer usage counter.
    * `flags` (uint16_t): Page-level settings.
    * `pageType` (uint8_t): Stores the active page type number.
    * `padding` (array of 3 bytes): Extra padding bytes to align the header to an 8-byte boundary.

### Step 2: Create the Database Page Structure
* Define constants calculating sizes:
  * `PAGE_HEADER_SIZE`: Size of the packed header struct.
  * `PAGE_DATA_SIZE`: Capacity remaining for raw page data (`PAGE_SIZE - PAGE_HEADER_SIZE`).
* Define `struct Page`:
  * Declare a variable `header` of type `PageHeader`.
  * Declare a variable `data` as a raw byte array of size `PAGE_DATA_SIZE`.
  * Implement `void Reset()`:
    * Clear all memory bytes inside the page structure to `0`.
    * Re-initialize the header's Page ID to `INVALID_PAGE_ID` and the LSN to `INVALID_LSN`.
  * Implement getter methods returning pointers to the start of the `data` array (both const and non-const versions).

### Step 3: Implement Compile-Time Assertions
* Add compile-time checks at the bottom of the file to verify:
  * The size of the `PageHeader` struct is exactly 28 bytes.
  * The size of the `Page` struct is exactly 4096 bytes.

## 3. C++ Systems Features Primer

* **Struct Padding**: CPUs read memory in word sizes (e.g. 4 or 8 bytes). To optimize speed, compilers insert invisible padding bytes inside structs so that variables align with word boundaries. For example, placing a `uint8_t` followed by a `uint32_t` usually causes the compiler to insert 3 padding bytes between them.
* **Compiler Packing (`#pragma pack(push, 1)`)**: In storage engines, padded bytes waste file space and vary across OS architectures. We disable padding using `#pragma pack(push, 1)` (tells the compiler to pack struct members with 1-byte alignment) and restore defaults using `#pragma pack(pop)`.
* **Compile-Time Assertions (`static_assert(condition, message)`)**: Standard assertions run when the program is executing. If a bug is in the layout, the compiler builds a corrupt program anyway. `static_assert` runs during compilation. If the condition is false, compiler execution halts immediately, preventing compilation of a corrupt binary.
* **`std::memset`**: A standard memory utility from `<cstring>` that fills a continuous block of memory with a specific byte value. We use `std::memset(this, 0, PAGE_SIZE)` to zero out all data bytes.

---

## 4. Functional & Structural Requirements
* **No Padding**: The `PageHeader` struct must not contain compiler-inserted padding bytes.
* **Header Limit**: The size of the `PageHeader` struct must be exactly 28 bytes (`sizeof(PageHeader) == 28`).
* **Frame Size**: The total size of the `Page` struct must be exactly 4096 bytes (`sizeof(Page) == 4096`).
* **Zero Initialized**: `Reset()` must clear all page bytes and restore invalid sentinel constants.
