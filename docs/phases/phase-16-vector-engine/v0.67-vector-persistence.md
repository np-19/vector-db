## 1. Problem Statement

## Visual Model

Vector embeddings are arrays of floating-point numbers that must be persisted on disk inside slotted page records to survive restarts. Raw float arrays cannot be stored in record slots directly as typed objects — they must be converted to binary byte buffers. We need to implement a **`VectorSerializer`** class that serializes `Vector` objects into compact binary byte arrays (with a 4-byte dimension header followed by raw float bytes) and deserializes them back, enabling vector storage inside slotted page record slots.

## 2. Step-by-Step Instructions

### Step 1: Design the Vector Serializer
* Create a header file `src/vector/vector_serializer.h` within `namespace DB`.
* Include the vector, cstdint, cstring, and stdexcept headers.
* Define `class VectorSerializer`:
  * Declare public static methods:
    * `static std::vector<uint8_t> Serialize(const Vector& vec)`
    * `static Vector Deserialize(const std::vector<uint8_t>& bytes)`

### Step 2: Implement Serialization
* Implement `Serialize(vec)`:
  * Compute `uint32_t dimensions = vec.GetDimensions()`.
  * Compute `size_t float_bytes = dimensions * sizeof(float)`.
  * Allocate a byte vector: `std::vector<uint8_t> bytes(sizeof(uint32_t) + float_bytes)`.
  * Copy dimension header: `std::memcpy(bytes.data(), &dimensions, sizeof(uint32_t))`.
  * Copy float data: `std::memcpy(bytes.data() + sizeof(uint32_t), vec.Data(), float_bytes)`.
  * Return `bytes`.

### Step 3: Implement Deserialization
* Implement `Deserialize(bytes)`:
  * Validate minimum size: if `bytes.size() < sizeof(uint32_t)`, throw `std::runtime_error`.
  * Read dimension header: `std::memcpy(&dimensions, bytes.data(), sizeof(uint32_t))`.
  * Validate expected byte size: if `bytes.size() != sizeof(uint32_t) + (dimensions * sizeof(float))`, throw `std::runtime_error`.
  * Allocate float vector: `std::vector<float> elements(dimensions)`.
  * Copy float data: `std::memcpy(elements.data(), bytes.data() + sizeof(uint32_t), dimensions * sizeof(float))`.
  * Return `Vector(std::move(elements))`.

## 3. C++ Systems Features Primer

* **Binary Serialization Layout**:
  ```
  [ 4 bytes: uint32_t dimensions | N * 4 bytes: float data ]
  ```
  Total size = `4 + (dimensions * 4)` bytes.
* **`std::memcpy` for Float Copying**: Floats are stored in memory as 32-bit IEEE 754 binary patterns. We can copy them directly as raw bytes without interpreting the bit patterns. `memcpy(dest, src, n_bytes)` copies `n_bytes` bytes from `src` to `dest` without any type conversion.
* **Alignment Safety**: When reading floats back from byte arrays, misaligned float reads crash on some CPU architectures. Using `memcpy` into a properly declared `std::vector<float>` ensures alignment correctness automatically.
* **Size Verification**: Checking that the byte buffer size matches the expected size prevents buffer overreads and heap corruption during deserialization of corrupted or truncated data.

---

## 4. Functional & Structural Requirements
* **Correct Size**: Serialized byte size must exactly equal `sizeof(uint32_t) + dimensions * sizeof(float)`.
* **Round-Trip Fidelity**: Deserializing a freshly serialized vector must produce bit-identical float values.
* **Validation Guards**: Both methods must validate sizes and throw `std::runtime_error` on format violations.
* **Move Semantics**: The deserialized `Vector` must be returned via `std::move()` to avoid float array copies.
